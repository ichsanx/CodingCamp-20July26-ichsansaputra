# Expense & Budget Visualizer

A mobile-friendly expense tracker built with HTML, CSS, and vanilla JavaScript for the Coding Camp assignment.

## Core features

- Add transactions with item name, amount, date, and category
- Required-field validation
- Scrollable transaction history
- Delete transactions
- Automatically updated total expenses
- Spending distribution pie/doughnut chart drawn with the Canvas API
- Browser Local Storage persistence
- Responsive design for mobile and desktop

## Optional challenges implemented

This project implements all five optional challenges:

1. Custom categories
2. Monthly summary view
3. Sort transactions by amount or category
4. Highlight spending over a monthly limit
5. Dark/light mode toggle

## Run locally

Open `index.html` in a modern browser. No installation or backend is required.

## GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Click **Save** and wait for the published URL.
